# Changelog

## 0.1.0

- Initial release of flutter_rust_ocr plugin.
- Rust-powered offline OCR engine with zero cloud dependency.
- Image quality analysis (blur, brightness, contrast).
- Document extraction with configurable JSON templates.
- Machine Readable Zone (MRZ) parser for passports and national ID cards.
- Realtime streaming session with backpressure support.
- Batch processing queue with progress reporting.
